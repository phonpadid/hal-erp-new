# ປະກາດ: ຕ້ອງອັບໂຫລດລາຍເຊັນກ່ອນ ຈຶ່ງຈະສະເໜີ ຫຼື ອະນຸມັດເອກະສານໄດ້

ຮຽນ ຜູ້ໃຊ້ລະບົບ e-Approval ທຸກທ່ານ

ຕັ້ງແຕ່ວັນທີ ____ / ____ / ______ ເປັນຕົ້ນໄປ ລະບົບຈະຮຽກຮ້ອງໃຫ້ມີ **ລາຍເຊັນ** ຢູ່ໃນບັນຊີຜູ້ໃຊ້ຂອງທ່ານກ່ອນ
ຈຶ່ງຈະສາມາດ:

- **ສະເໜີ (Submit)** ເອກະສານ — ລາຍເຊັນຂອງທ່ານຈະຖືກປະທັບໃສ່ເອກະສານໃນຊ່ອງ "ຜູ້ສະເໜີ"
- **ອະນຸມັດ (Approve)** ເອກະສານ — ລາຍເຊັນຂອງທ່ານຈະຖືກປະທັບໃສ່ຂັ້ນທີ່ທ່ານອະນຸມັດ

ການ **ປະຕິເສດ (Reject)** ແລະ **ສົ່ງກັບ (Return)** ບໍ່ຕ້ອງໃຊ້ລາຍເຊັນ ແລະ ຍັງໃຊ້ໄດ້ຕາມປົກກະຕິ.
ການບັນທຶກແບບຮ່າງ (Save draft) ກໍຍັງໃຊ້ໄດ້ຕາມປົກກະຕິ.

## ເປັນຫຍັງ

ເອກະສານ PDF ທີ່ພິມອອກຈາກລະບົບຈະສະແດງລາຍເຊັນທີ່ມີຢູ່ **ໃນຂະນະທີ່ກົດອະນຸມັດ** ເທົ່ານັ້ນ — ຖ້າຕອນນັ້ນຍັງບໍ່ມີ
ລາຍເຊັນ ຊ່ອງນັ້ນຈະຫວ່າງເປົ່າຖາວອນ ແລະ ອັບໂຫລດຍ້ອນຫລັງແກ້ບໍ່ໄດ້. ການບັງຄັບໃຫ້ມີລາຍເຊັນກ່ອນຈຶ່ງເປັນທາງດຽວ
ທີ່ຮັບປະກັນວ່າເອກະສານທຸກໃບພິມອອກມາຄົບຖ້ວນ.

## ສິ່ງທີ່ຕ້ອງເຮັດ (ໃຊ້ເວລາປະມານ 1 ນາທີ)

1. ເຂົ້າສູ່ລະບົບ ແລ້ວໄປທີ່ **ໜ້າໂປຣໄຟລ໌** (`/new/profile`) — ກົດຊື່ຂອງທ່ານມຸມຂວາເທິງ → Profile
2. ໃນກ່ອງ **ລາຍເຊັນ** ກົດ **ອັບໂຫລດລາຍເຊັນ**
3. ເລືອກຮູບລາຍເຊັນ (PNG ຫຼື JPEG, ບໍ່ເກີນ 1 MB) — ຖ່າຍຮູບລາຍເຊັນບົນເຈ້ຍຂາວກໍໄດ້
4. ຕັດຮູບໃຫ້ພໍດີ ແລ້ວກົດ **ໃຊ້ຮູບນີ້** — ລະບົບຈະລົບພື້ນຫລັງໃຫ້ອັດຕະໂນມັດ

ຫລັງອັບໂຫລດແລ້ວ ປຸ່ມ ສະເໜີ / ອະນຸມັດ ຈະກັບມາໃຊ້ໄດ້ທັນທີ ໂດຍບໍ່ຕ້ອງອອກຈາກລະບົບ.

> ຜູ້ໃຊ້ **ແອັບມືຖື**: ການອັບໂຫລດລາຍເຊັນເຮັດໄດ້ຜ່ານເວັບເທົ່ານັ້ນ. ຖ້າກົດອະນຸມັດໃນມືຖືແລ້ວເຫັນຂໍ້ຄວາມ
> "A signature is required…" ໃຫ້ເຂົ້າເວັບໄປອັບໂຫລດກ່ອນ ແລ້ວກັບມາອະນຸມັດຕໍ່ໄດ້.
