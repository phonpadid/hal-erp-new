# ບົດນຳສະເໜີ: ລະບົບ ERP ອະນຸມັດເອກະສານ + ຄວບຄຸມງົບປະມານ (Multi-Company)

> ບົດນຳສະເໜີສຳລັບຫົວໜ້າ — ສະຫຼຸບ flow ການເຮັດວຽກທັງໝົດຂອງລະບົບທີ່ພັດທະນາສຳເລັດແລ້ວໃນປັດຈຸບັນ

---

## 1. ບົດນຳ

ລະບົບ ERP ນີ້ແມ່ນລະບົບບໍລິຫານເອກະສານ ແລະ ການອະນຸມັດແບບຄົບວົງຈອນ ຮອງຮັບຫຼາຍບໍລິສັດ (Multi-Company) ໃນຖານຂໍ້ມູນດຽວ ໂດຍມີຈຸດເດັ່ນຄື:

- **ຄວບຄຸມງົບປະມານແບບ Real-time** — ຈອງງົບ (Reserve) ຕອນສົ່ງເອກະສານ, ຕັດງົບຕົວຈິງ (Actual) ຕອນຮັບເຄື່ອງ/ຈ່າຍເງິນ, ຄືນງົບສ່ວນທີ່ບໍ່ໄດ້ໃຊ້ (Release) ອັດຕະໂນມັດ
- **ຂະບວນການອະນຸມັດຫຼາຍຂັ້ນຕອນ** — ກຳນົດເສັ້ນທາງອະນຸມັດໄດ້ເອງຕາມປະເພດເອກະສານ, ມີການມອບສິດແທນ (Delegation), ຕິດຕາມ SLA ແລະ ແຈ້ງເຕືອນເມື່ອຊັກຊ້າ
- **ຕັ້ງຄ່າໄດ້ ບໍ່ຕ້ອງຂຽນໂຄດໃໝ່** — ປະເພດເອກະສານ, ຟອມ, ເສັ້ນທາງອະນຸມັດ ລ້ວນແຕ່ຕັ້ງຄ່າຜ່ານໜ້າ Admin ໄດ້ທັງໝົດ
- **ຮອງຮັບຫຼາຍສະກຸນເງິນ** — ລັອກອັດຕາແລກປ່ຽນຕອນສົ່ງເອກະສານ, ຄິດໄລ່ກຳໄລ/ຂາດທຶນຈາກອັດຕາແລກປ່ຽນ (FX Gain/Loss) ຕອນຈ່າຍເງິນ
- **ເຊື່ອມຕໍ່ຮອດບັນຊີ** — ລົງບັນຊີ (GL Posting) ອັດຕະໂນມັດ ພ້ອມອາກອນຫັກ ນະ ທີ່ຈ່າຍ (WHT) ແລະ ອອກລາຍງານການເງິນໄດ້

ສະຖາປັດຕະຍະກຳ: **Backend** NestJS + PostgreSQL + MikroORM · **Frontend** Vue 3 + PrimeVue · ພັດທະນາແບບ Spec-driven (OpenSpec) — ປັດຈຸບັນສຳເລັດແລ້ວ **111 changes** ກວມ **57 capabilities**

## 2. ພາບລວມ Flow ຫຼັກຂອງລະບົບ (End-to-End)

```
ເຂົ້າສູ່ລະບົບ (Login)
   ↓
ເລືອກບໍລິສັດ (Select Company)
   ↓
ສ້າງເອກະສານ (Draft) — ເລືອກປະເພດ, ຕື່ມຟອມ, ໃສ່ລາຍການ
   ↓
ສົ່ງອະນຸມັດ (Submit) → ຈອງງົບປະມານ (Budget Reserve) + ຈອງໂຄຕ້າ (Quota Reserve)
   ↓                     + ອອກເລກທີເອກະສານ + ລັອກອັດຕາແລກປ່ຽນ
ຂະບວນການອະນຸມັດ — ຫຼາຍຂັ້ນຕອນຕາມ Workflow ທີ່ຕັ້งຄ່າໄວ້
   ↓  (ແຈ້ງເຕືອນຜູ້ອະນຸມັດ, ຕິດຕາມ SLA, ມອບສິດແທນໄດ້)
   ├─ ອະນຸມັດຄົບທຸກຂັ້ນ → ດຳເນີນ Post-Action (ຕັດງົບ, ໂອນງົບ, ສ້າງເອກະສານຕໍ່ເນື່ອງ...)
   └─ ປະຕິເສດ/ຍົກເລີກ → ຄືນງົບ + ຄືນໂຄຕ້າ ອັດຕະໂນມັດ
   ↓
ການຈ່າຍເງິນ — Ready to Pay → ສ້າງ Payment Batch → Export ໄຟລ໌ທະນາຄານ
   ↓            → Import ຜົນການຈ່າຍ → ແນບໃບບິນ (Slip)
ລົງບັນຊີ (GL Posting) — ພ້ອມ FX Gain/Loss + ອາກອນ WHT
   ↓
ລາຍງານ — ງົບປະມານ, ການອະນຸມັດ, ບັນຊີ, ລາຍງານລວມກຸ່ມບໍລິສັດ
```

## 3. ລາຍລະອຽດ Flow ແຕ່ລະສ່ວນ (ທີ່ສຳເລັດແລ້ວທັງໝົດ)

### 3.1 ການເຂົ້າສູ່ລະບົບ ແລະ ຄວາມປອດໄພ (Auth)
- ເຂົ້າສູ່ລະບົບດ້ວຍ JWT, ລືມລະຫັດຜ່ານ / ຕັ້ງລະຫັດໃໝ່ຜ່ານອີເມວ, ຢືນຢັນອີເມວ
- ໜ້າໂປຣໄຟລ໌ຜູ້ໃຊ້: ປ່ຽນລະຫັດຜ່ານ, ອັບໂຫຼດຮູບໂປຣໄຟລ໌, ອັບໂຫຼດ**ລາຍເຊັນ** (ພ້ອມລຶບພື້ນຫຼັງອັດຕະໂນມັດ) ເພື່ອໃຊ້ໃນເອກະສານ PDF

### 3.2 ຫຼາຍບໍລິສັດ (Multi-Company)
- ຜູ້ໃຊ້ໜຶ່ງຄົນສັງກັດໄດ້ຫຼາຍບໍລິສັດ ແລະ **ສະຫຼັບບໍລິສັດ** ໄດ້ໂດຍບໍ່ຕ້ອງອອກຈາກລະບົບ
- ຂໍ້ມູນທຸກຢ່າງແຍກຕາມບໍລິສັດຢ່າງເຂັ້ມງວດ (Company Isolation) — ຂໍ້ມູນບໍ່ຮົ່ວຂ້າມບໍລິສັດ
- ຈັດການ: ບໍລິສັດ, ພະແນກ (ແບບຕົ້ນໄມ້), ປີງົບປະມານ (ພ້ອມປິດປີ), ວັນພັກ/ປະຕິທິນເຮັດວຽກ (ໃຊ້ຄິດໄລ່ SLA ຕາມວັນເຮັດວຽກຕົວຈິງ)

### 3.3 ສິດການນຳໃຊ້ ແລະ ພະນັກງານ (RBAC + Employee)
- ກຳນົດສິດແບບ **Permission Code** (ເຊັ່ນ `DOC_PR_APPROVE`) — ບໍ່ອີງໃສ່ຊື່ Role
- ຈັດການ Role, Permission, ມອບສິດໃຫ້ຜູ້ໃຊ້ ທັງແບບລາຍຄົນ ແລະ **ແບບ Bulk** (ເລືອກຫຼາຍລາຍການພ້ອມກັນ)
- ທະບຽນພະນັກງານຄົບວົງຈອນ: ສ້າງພະນັກງານ → ສ້າງບັນຊີຜູ້ໃຊ້ → Onboard → ຢືນຢັນບັນຊີ → ລາອອກ (Resign)
- ໜ້າຈໍ Frontend ສະແດງ/ເຊື່ອງປຸ່ມຕາມສິດຂອງຜູ້ໃຊ້ໃນບໍລິສັດທີ່ກຳລັງໃຊ້ງານ

### 3.4 ຂໍ້ມູນຫຼັກ (Master Data)
- ສິນຄ້າ/ລາຍການ (Items), ຜູ້ສະໜອງ (Vendors) — ເປີດ/ປິດການໃຊ້ງານໄດ້
- **ບັນຊີທະນາຄານຜູ້ສະໜອງ** — ເພີ່ມ/ແກ້ໄຂ, ຕັ້ງບັນຊີຫຼັກ, ເບິ່ງປະຫວັດການປ່ຽນແປງ (ໃຊ້ຕອນສ້າງໄຟລ໌ຈ່າຍເງິນ)

### 3.5 ຫຼາຍສະກຸນເງິນ (Multi-Currency)
- ຈັດການສະກຸນເງິນ ແລະ ອັດຕາແລກປ່ຽນ
- **ລັອກອັດຕາແລກປ່ຽນຕອນສົ່ງເອກະສານ** — ບໍ່ຄິດໄລ່ຄືນພາຍຫຼັງ; ສ່ວນຕ່າງຕອນຈ່າຍເງິນບັນທຶກເປັນ FX Gain/Loss ເຂົ້າບັນຊີ
- ສະແດງຈຳນວນເງິນຕາມຈຳນວນຈຸດທົດສະນິຍົມຂອງແຕ່ລະສະກຸນເງິນ

### 3.6 ຄວບຄຸມງົບປະມານ (Budget Control) — ຫົວໃຈຫຼັກຂອງລະບົບ
- ບັນຊີງົບປະມານແບບ **Ledger ບັນທຶກຢ່າງດຽວ (Append-only)** — ກວດສອບຍ້ອນຫຼັງໄດ້ທຸກລາຍການ
- Flow: **ຈອງ (Reserve)** ຕອນສົ່ງເອກະສານ → **ຕັດຕົວຈິງ (Actual/Settle)** ຕອນຮັບເຄື່ອງ/ຈ່າຍເງິນ → **ຄືນສ່ວນເຫຼືອ (Release)** ອັດຕະໂນມັດ
- ປະຕິເສດ/ຍົກເລີກເອກະສານ → **ຄືນງົບອັດຕະໂນມັດ 100%**
- **ໂອນງົບ (Transfer)** ລະຫວ່າງງົບພາຍໃນບໍລິສັດ ແລະ **ປັບງົບ (Adjust)** ເພີ່ມ/ຫຼຸດ — ຜ່ານການອະນຸມັດ
- ກວດງົບເປັນລາຍລາຍການ (Line-item) ແລະ ປ້ອງກັນການຈອງເກີນງົບດ້ວຍ Database Lock (ທົດສອບ Concurrency ແລ້ວ)
- ໜ້າຈໍ: ລາຍການງົບ, ລາຍລະອຽດ + Ledger, ເສັ້ນສະແດງ Waterfall

### 3.7 ໂຄຕ້າ (Quota Management)
- ກຳນົດໂຄຕ້າການໃຊ້ (ເຊັ່ນ ຈຳນວນຄັ້ງ/ຈຳນວນເງິນ ຕໍ່ຄົນ ຕໍ່ໄລຍະ)
- ຈອງໂຄຕ້າຕອນສົ່ງເອກະສານ, ຄືນອັດຕະໂນມັດເມື່ອຖືກປະຕິເສດ, **ຍົກຍອດ (Carry-forward)** ຂ້າມໄລຍະໄດ້
- ໜ້າ Admin ປັບໂຄຕ້າ ແລະ ເບິ່ງການໃຊ້ງານແບບເຈາະເລິກ

### 3.8 ລະບົບເອກະສານ (Document Engine)
- **ຕັ້ງຄ່າໄດ້ທັງໝົດ**: ໝວດເອກະສານ, ປະເພດເອກະສານ, ຟອມ (Form Template + Fields), ການເຊື່ອມພະແນກ-ປະເພດເອກະສານ
- ສ້າງເອກະສານ Draft → ຕື່ມຟອມ → ໃສ່ລາຍການ (ພ້ອມຜູກບັນຊີ GL, ງົບປະມານ, ໂຄຕ້າ) → ສົ່ງອະນຸມັດ
- **ອອກເລກທີເອກະສານອັດຕະໂນມັດ** ບໍ່ຊ້ຳກັນ (ປ້ອງກັນເລກຊ້ຳດ້ວຍ Database Lock)
- **ສາຍເອກະສານຕໍ່ເນື່ອງ (Ref Chain)**: PR → PO → GR → Invoice — ສ້າງເອກະສານຕໍ່ຈາກເອກະສານເກົ່າໄດ້ ພ້ອມລະບົບ Matching ແລະ ການຮັບເຄື່ອງ (Receiving)
- ແນບໄຟລ໌ເອກະສານ (Attachments), **Export PDF ແບບໜັງສືລາວ** ພ້ອມລາຍເຊັນຜູ້ອະນຸມັດ

### 3.9 ຂະບວນການອະນຸມັດ (Approval Workflow)
- ຕັ້ງຄ່າ Workflow ຫຼາຍຂັ້ນຕອນຕໍ່ປະເພດເອກະສານ — ກຳນົດຜູ້ອະນຸມັດຕາມຕຳແໜ່ງ/ພະແນກ/ລະດັບວົງເງິນ
- **ກ່ອງອະນຸມັດ (Approval Inbox)** — ເບິ່ງເອກະສານທີ່ລໍຖ້າ, ອະນຸມັດ/ປະຕິເສດ ພ້ອມໝາຍເຫດ
- **ມອບສິດແທນ (Delegation)** — ມອບໄດ້ແຕ່ຫ້າມມອບຕໍ່ເປັນລູກໂສ້; **ຫ້າມອະນຸມັດເອກະສານຕົນເອງ** ເດັດຂາດ
- **SLA + Escalation** — ຄິດໄລ່ຕາມວັນເຮັດວຽກຕົວຈິງ (ຫັກວັນພັກ), ແຈ້ງເຕືອນ/ຍົກລະດັບເມື່ອຄ້າງດົນເກີນກຳນົດ
- ບັນທຶກປະຫວັດການອະນຸມັດ (Approval Log) ແບບບັນທຶກຢ່າງດຽວ — ກວດສອບໄດ້ທຸກຂັ້ນຕອນ
- **Post-Action ອັດຕະໂນມັດເມື່ອອະນຸມັດຄົບ**: ຕັດງົບ, ໂອນ/ປັບງົບ, ປັບຕຳແໜ່ງພະນັກງານ (Promotion), ລາອອກ (Resignation), ຮັບເຄື່ອງ, **ສ້າງເອກະສານຕໍ່ເນື່ອງອັດຕະໂນມັດ** (Successor Document)

### 3.10 ການແຈ້ງເຕືອນ (Notifications)
- ແຈ້ງເຕືອນໃນລະບົບ: ເອກະສານລໍຖ້າອະນຸມັດ, ຜົນການອະນຸມັດ (ຜ່ານ/ບໍ່ຜ່ານ)
- ຂໍ້ຄວາມແບບ Template ຕັ້ງຄ່າໄດ້ ພ້ອມຕົວແປຈາກເອກະສານ + ໜ້າກ່ອງຂໍ້ຄວາມ (Inbox) ໝາຍອ່ານແລ້ວໄດ້

### 3.11 ການຈ່າຍເງິນ (Payment)
- **Ready to Pay** — ລາຍການເອກະສານທີ່ອະນຸມັດແລ້ວພ້ອມຈ່າຍ
- **Payment Batch** — ຮວມຫຼາຍລາຍການເປັນຊຸດ → **Export ໄຟລ໌ໃຫ້ທະນາຄານ** (ດຶງບັນຊີທະນາຄານຜູ້ສະໜອງຕົວຈິງ + ຄິດໄລ່ WHT) → **Import ຜົນການຈ່າຍ** ຄືນເຂົ້າລະບົບ
- ອັບໂຫຼດ/ຈັດການ**ໃບບິນໂອນເງິນ (Payment Slip)** ຕິດກັບລາຍການຈ່າຍ
- ຈ່າຍແລ້ວ → **ລົງບັນຊີ GL ອັດຕະໂນມັດ** ພ້ອມ FX Gain/Loss ແລະ ອາກອນ WHT

### 3.12 ບັນຊີ ແລະ ອາກອນ (Accounting + Tax)
- ຜັງບັນຊີ (Chart of Accounts) + ກຳນົດບົດບາດບັນຊີ (AP, Cash, FX, WHT...)
- ສະໝຸດບັນຊີ (Journal) ເບິ່ງລາຍການລົງບັນຊີໄດ້
- ອາກອນ: ລະຫັດອາກອນ VAT/WHT, ສະຫຼຸບ VAT
- **ລາຍງານການເງິນ**: ໃບດຸ່ນດ່ຽງທົດລອງ (Trial Balance), ໃບລາຍງານຜົນໄດ້ຮັບ (Income Statement), ໃບດຸ່ນດ່ຽງຊັບສິນ (Balance Sheet), ບັນຊີແຍກປະເພດ (Account Ledger)

### 3.13 ລາຍງານ ແລະ Dashboard
- ລາຍງານ: ຍອດງົບປະມານ, ການໃຊ້ງົບ (Utilization), ອາຍຸການອະນຸມັດຄ້າງ (Approval Aging), ໂຄຕ້າຄົງເຫຼືອ, ກວດສອບງົບ (Budget Audit), ສະຫຼຸບເອກະສານ, ຍອດຊື້ຕາມຜູ້ສະໜອງ
- **ລາຍງານລວມກຸ່ມບໍລິສັດ (Group Consolidated)** — ເບິ່ງງົບປະມານລວມທຸກບໍລິສັດ (ອ່ານຢ່າງດຽວ)
- Export CSV ໄດ້ທຸກລາຍງານ + Dashboard ໜ້າຫຼັກ

### 3.14 ອື່ນໆ
- **External API + API Key** — ໃຫ້ລະບົບພາຍນອກເຊື່ອມຕໍ່ໄດ້ຢ່າງປອດໄພ (ສ້າງ/ຖອນ Key ໄດ້)
- **ຫຼາຍພາສາ (i18n)** — ຮອງຮັບພາສາລາວ, ອັງກິດ, ຈີນ
- ບັນທຶກການຕັ້ງຄ່າຜູ້ໃຊ້ (Theme ມືດ/ແຈ້ງ, Layout) ຕິດຕົວຂ້າມອຸປະກອນ

| Concurrency Safe | ໃຊ້ Database Lock ປ້ອງກັນຈອງງົບເກີນ / ເລກທີຊ້ຳ ພ້ອມ Test ຮອງຮັບ |
